## About Me

심리학 전공과 통계학 복수전공에서 쌓은 분석 역량과 소프트웨어 개발 경험을 바탕으로, 데이터에서 의미를 발견하고 분석 결과를 실제 도구와 서비스로 구현할 수 있는 데이터 분석가를 지향합니다.
분석에서는 재현성, 적절한 검증 설계와 결과의 해석 범위를 중요하게 생각합니다.

## Statistical Analysis Work

학부에서 통계학을 복수전공하며 수행한 분석을 문제 설정, 방법 선택, 결과 해석과 한계 중심으로 재구성했습니다.

| 분석 | 핵심 내용 | 방법 |
|---|---|---|
| [Heart Failure Model Validation](https://github.com/stonetiger95/heart-failure-model-validation) | 심부전 임상자료에서 LDA·QDA·SVM·ANN을 동일한 반복 교차검증으로 비교하고 성능 지표의 trade-off를 분석 | R, repeated CV, ROC-AUC, sensitivity, specificity |

| [Face Impression Multivariate Analysis](https://github.com/stonetiger95/face-impression-multivariate-analysis) | 66개 얼굴 자극의 14개 인상 평정을 PCA·요인분석·군집분석으로 요약하고 잠재 구조를 비교 | R, PCA, PCFA, MLFA, clustering |
| [Statistics Mini Analyses](https://github.com/stonetiger95/statistics-mini-analyses) | 주가 시계열, 반복검정 오류, 육상 기록의 공통 차원, 범주형 자료의 연관 구조를 분석한 네 가지 사례 | R, ARIMA, multiple testing, PCA/FA, correspondence analysis |
